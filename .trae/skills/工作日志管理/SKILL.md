# 工作日志管理专家 (Working Log Manager)

## 核心规则

**每次有实质性工作时，必须立即创建或更新工作日志。** 这是硬性要求，不是可选项。

---

## 日志存储位置

```
C:\Users\30817\Desktop\ai工作日志记忆\
├── 2026-04-17/
│   ├── ESP32-P4-LVGL-Demo配置烧录/        ← 主题文件夹
│   │   └── ESP32-P4-LVGL-Demo配置烧录-16-30-00.md
│   └── 另一个主题/
│       └── 另一个主题-14-20-10.md
└── SUMMARY.md                               ← 跨项目汇总索引
```

**规则：**
- **每日目录**：`C:\Users\30817\Desktop\ai工作日志记忆\{年-月-日}\`
- **主题文件夹**：每个工作主题一个独立文件夹
- **日志文件**：`{主题名}-{时-分-秒}.md`，如 `ESP32-P4-LVGL-Demo配置烧录-16-30-00.md`
- **汇总索引**：`SUMMARY.md` 维护近期工作概览

**注意**：同一主题的工作追加到同一个主题文件夹下，多次会话产生多个时间戳文件。

## 操作流程

### 1. 工作开始时 — 检查并创建日志

**步骤：**
1. 获取当前日期 `{YYYY-MM-DD}` 和时间 `{HH-MM-SS}`
2. 检查 `C:\Users\30817\Desktop\ai工作日志记忆\{YYYY-MM-DD}\` 目录是否存在
3. 检查该日期下是否有对应的主题文件夹
4. 如无主题文件夹 → 创建：`C:\Users\30817\Desktop\ai工作日志记忆\{YYYY-MM-DD}\{主题名}\`
5. 创建日志文件：`C:\Users\30817\Desktop\ai工作日志记忆\{YYYY-MM-DD}\{主题名}\{主题名}-{HH-MM-SS}.md`

**示例路径：**
```
C:\Users\30817\Desktop\ai工作日志记忆\2026-04-17\
├── ESP32-P4-LVGL-Demo配置烧录\
│   └── ESP32-P4-LVGL-Demo配置烧录-16-30-00.md
```

### 2. 工作过程中 — 实时更新
- 每完成一个步骤 → 在日志中标记 ✅
- 遇到阻塞/错误 → 记录问题和尝试的解决方案
- 发现重要信息 → 添加到"关键决策"或"遇到的问题"

### 3. 工作结束时 — 完善日志
- 确认所有步骤状态正确
- 补全修改文件清单（从git diff或实际文件操作获取）
- 填写"下次会话须知"（关键上下文，方便下次快速进入状态）
- 更新 `SUMMARY.md` 索引

### 4. SUMMARY.md 维护
每次有新日志时，在汇总文件顶部追加一行：

```markdown
## 2026-04-17
- [ESP32-P4-LVGL-Demo配置烧录](./2026-04-17/ESP32-P4-LVGL-Demo配置烧录/ESP32-P4-LVGL-Demo配置烧录-16-30-00.md) — 配置LVGL开发环境并烧录
```

**永不删除**：所有工作日志永久保留，无需归档或清理。

## 与记忆系统联动

工作日志完成后，提取关键信息保存到项目记忆：
- **Bug修复** → 记录到 memory 中的 project 类型记忆
- **架构决策** → 记录原因和取舍，方便后续参考
- **用户偏好** → 如果发现用户有特殊偏好，保存到 feedback 记忆
- **项目状态** → 当前进度、阻塞项、下一步计划

## 注意事项

1. **立即记录**：开始工作时就创建日志，不要最后补
2. **实时更新**：完成一步记录一步，保持状态同步
3. **时间精确**：使用系统时间，文件名 HH-MM-SS，日志内 YYYY-MM-DD HH:MM:SS
4. **主题归类**：按主题名创建独立文件夹，同一主题多次会话的文件放一起
5. **文件归类**：按日期分目录 → 主题文件夹 → 日志文件，SUMMARY.md 汇总索引
6. **简洁清晰**：用列表和表格，避免大段文字
7. **状态明确**：每步标注 ✅/⏳/❌
8. **上下文传递**："下次会话须知"是关键，确保下次能快速恢复
9. **不记录敏感信息**：密码、Token等不要写入日志
